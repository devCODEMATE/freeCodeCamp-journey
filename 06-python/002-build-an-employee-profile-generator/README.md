# Build an Employee Profile Generator

## English

### Description

This workshop creates an employee profile using variables, strings, numbers, concatenation, f-strings, and string slicing.

It was completed as part of the **freeCodeCamp Python V9 curriculum**.

### Concepts Practiced

- Variables
- Strings
- Integers
- String concatenation with `+`
- Augmented assignment with `+=`
- Type conversion with `str()`
- F-strings
- String slicing
- Positive and negative indexes
- Output with `print()`

### Main Output

```text
Employee: John Doe | Age: 28 | Position: Data Analyst | Salary: $75000
```

### Employee Code

The program extracts the following information from `DEV-2026-JD-001`:

- Department: `DEV`
- Year: `2026`
- Initials: `JD`
- Identification number: `001`

### Technologies

- Python 3
- freeCodeCamp
