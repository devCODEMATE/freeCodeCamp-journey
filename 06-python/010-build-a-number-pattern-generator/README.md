# Build a Number Pattern Generator

## English

### Description

This lab creates a Python function that generates a number pattern from `1` up to a given positive integer.

The numbers are returned as a single string separated by spaces. The function also validates that the argument is an integer greater than zero.

It was completed as part of the **freeCodeCamp Python V9 curriculum**.

### Concepts Practiced

- Function definitions
- Function parameters
- Returning values with `return`
- Type validation with `isinstance()`
- Conditional statements
- Comparison operators
- `for` loops
- The `range()` function
- Type conversion with `str()`
- String concatenation
- Augmented assignment with `+=`
- Removing surrounding spaces with `strip()`

### Validation Rules

The function verifies that:

1. The argument is an integer.
2. The integer is greater than `0`.

### Example

```python
number_pattern(4)
```

Result:

```text
1 2 3 4
```
