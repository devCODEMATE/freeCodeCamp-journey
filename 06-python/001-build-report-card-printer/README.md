## 🇪🇸 Español

### Descripción

Primer workshop del currículo de Python de freeCodeCamp.

En este ejercicio se crean variables con diferentes tipos de datos. Luego se utilizan las funciones `print()`, `type()` e `isinstance()` para mostrar sus valores e identificar o comprobar sus tipos.

### Conceptos practicados

- Creación de variables
- Cadenas de texto (`str`)
- Valores booleanos (`bool`)
- Números enteros (`int`)
- Números decimales (`float`)
- Uso de la función `print()`
- Identificación de tipos con `type()`
- Verificación de tipos con `isinstance()`

### Código

```python
name = "Alice"

print(name, type(name))

is_student = True

print(is_student, type(is_student))

age = 20

print(age, type(age))

score = 80.5

print(isinstance(score, float))

print(score, type(score))
```

### Ejecución

Para ejecutar el programa, abre una terminal dentro de la carpeta del ejercicio y utiliza:

```bash
python main.py
```

En Windows también puedes utilizar:

```bash
py main.py
```

### Resultado esperado

```text
Alice <class 'str'>
True <class 'bool'>
20 <class 'int'>
True
80.5 <class 'float'>
```
