# Build a Movie Ticket Booking Calculator

## English

### Description

This workshop builds a movie ticket booking calculator that checks booking restrictions and calculates the final ticket price.

It was completed as part of the **freeCodeCamp Python V9 curriculum**.

### Concepts Practiced

- Boolean values
- Truthy and falsy values
- Conditional statements
- `if`, `elif`, and `else`
- Nested conditional statements
- Comparison operators
- Logical operators: `and` and `or`
- Variable updates
- Arithmetic operations
- Code indentation

### How It Works

The program:

1. Checks whether the user is old enough to book a ticket.
2. Verifies eligibility for evening shows.
3. Applies a membership discount when applicable.
4. Adds extra charges for weekend or evening shows.
5. Calculates service charges according to the seat type.
6. Calculates the final ticket price.

### Final Calculation

```text
Base price: 15
Extra charges: 2
Service charges: 3
Discount: 0
Final price: 20
```

### Main Output

```text
Final price of ticket: 20
```

### Funcionamiento

El programa:

1. Comprueba si el usuario tiene edad suficiente para reservar una entrada.
