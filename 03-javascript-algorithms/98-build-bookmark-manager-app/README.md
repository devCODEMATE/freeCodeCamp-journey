# 🔖 Bookmark Manager App

## 🇪🇸 Español

Este es el ejercicio número **98** de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue desarrollar una aplicación para administrar marcadores (bookmarks), permitiendo organizarlos por categorías, almacenarlos de forma persistente mediante `localStorage`, visualizarlos y eliminarlos cuando sea necesario.

### Funcionalidades

- Agregar nuevos bookmarks.
- Organizar bookmarks por categorías.
- Visualizar únicamente los bookmarks de una categoría seleccionada.
- Abrir enlaces en una nueva pestaña.
- Eliminar bookmarks existentes.
- Guardar la información en `localStorage`.
- Recuperar los datos almacenados al volver a abrir la aplicación.
- Validar la estructura de los datos almacenados.
- Mostrar un mensaje cuando una categoría no contiene bookmarks.
- Navegar entre las diferentes vistas de la aplicación.

- Persistir información utilizando `localStorage`.

## 🇺🇸 English

This is exercise **98** in my freeCodeCamp JavaScript journey.

The goal was to build a bookmark manager application that allows users to organize bookmarks by category, store them persistently using `localStorage`, display them, and remove them when needed.

### Features

- Add new bookmarks.
- Organize bookmarks by category.
- Display bookmarks for the selected category.
- Open links in a new browser tab.
- Delete existing bookmarks.
- Store data using `localStorage`.
- Restore saved bookmarks when reopening the application.
- Validate the structure of stored data.
- Display a message when a category has no bookmarks.
- Navigate between the different application views.
