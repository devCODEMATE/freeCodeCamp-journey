## 🇪🇸 Español

Este es el ejercicio número **100** de mi recorrido de JavaScript en freeCodeCamp.

- Crear tableros con un título.
- Agregar ideas al tablero.
- Eliminar ideas del tablero.
- Contar la cantidad de ideas almacenadas.
- Generar un resumen formateado con título, estado y descripción.
- Manejar tableros vacíos correctamente.

## 🇺🇸 English

This is exercise **100** in my freeCodeCamp JavaScript journey.

The goal was to build a system for organizing project ideas using object-oriented programming. The program allows users to create ideas, assign statuses, add them to a board, remove them, and generate a complete text summary.

### Features

- Define reusable statuses for project ideas.
- Create ideas with a title and description.
- Assign the pending status by default.
- Update the status of an idea.
- Create boards with a title.
- Add ideas to a board.
- Remove ideas from a board.
- Count the number of stored ideas.
- Generate a formatted summary with title, status, and description.
- Correctly handle empty boards.

### Available statuses

- `PENDING`: Pending Execution
- `SUCCESS`: Executed Successfully
- `FAILURE`: Execution Failed

### What I learned

- Create classes with `class`.
- Initialize properties through constructors.
- Create instances with different data.
- Use objects as status values.
- Set a default status when creating an instance.
- Update properties through class methods.
- Store class instances inside an array.
- Add elements with `.push()`.
- Find an instance position with `.indexOf()`.
- Remove elements with `.splice()`.
- Prevent errors by checking that the index is not `-1`.
- Get the number of elements with `.length`.
- Iterate through ideas with `.forEach()`.
- Build multiline output using template literals.
- Divide responsibilities between different classes.
- Model a simple system using object-oriented programming.
