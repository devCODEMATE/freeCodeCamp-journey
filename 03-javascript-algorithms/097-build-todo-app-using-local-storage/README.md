# ✅ Todo App using Local Storage

## 🇪🇸 Español

Este es el ejercicio número **97** de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue desarrollar una aplicación de tareas que permita crear, editar y eliminar tareas, manteniendo la información almacenada en el navegador mediante `localStorage`.

### Funcionalidades

- Crear nuevas tareas.
- Editar tareas existentes.
- Eliminar tareas.
- Guardar automáticamente las tareas en `localStorage`.
- Recuperar las tareas al volver a abrir la aplicación.
- Mostrar dinámicamente la lista de tareas.
- Confirmar antes de descartar cambios sin guardar.
- Validar que el título de la tarea no esté vacío.
- Generar identificadores únicos para cada tarea.
- Eliminar caracteres especiales de los identificadores para evitar problemas con el DOM.

## 🇺🇸 English

This is exercise **97** in my freeCodeCamp JavaScript journey.

The goal was to build a task management application that allows users to create, edit, and delete tasks while keeping the data stored in the browser using `localStorage`.

### Features

- Create new tasks.
- Edit existing tasks.
- Delete tasks.
- Automatically save tasks to `localStorage`.
- Restore tasks when reopening the application.
- Dynamically render the task list.
- Confirm before discarding unsaved changes.
- Validate that every task has a title.
- Generate unique identifiers for each task.
- Remove special characters from generated IDs to avoid DOM issues.

### What I learned

- Build a CRUD application using JavaScript.
- Persist data with `localStorage`.
- Serialize and deserialize data using `JSON.stringify()` and `JSON.parse()`.
- Locate elements inside arrays with `.findIndex()`.
- Add new tasks using `.unshift()`.
- Remove elements with `.splice()`.
- Dynamically render HTML using template literals.
- Use object destructuring while iterating through collections.
- Validate forms before saving data.
- Generate unique identifiers with `Date.now()`.
- Sanitize text using regular expressions to create safe HTML IDs.
- Show and hide interface components using CSS classes.
- Use the HTML `<dialog>` element to confirm user actions.
- Keep the application state synchronized with both the UI and local storage.
