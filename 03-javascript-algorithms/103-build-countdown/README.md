# ⏳ Countdown

## 🇪🇸 Español

Este es el ejercicio número **102** de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue desarrollar una función recursiva que genere un conteo regresivo desde un número dado hasta `1`, devolviendo el resultado como un array.

A diferencia de una solución tradicional, este ejercicio debía resolverse **únicamente utilizando recursividad**, sin emplear bucles (`for`, `while`), `Array.from()` ni métodos de iteración como `map()`, `filter()`, `reduce()` o `forEach()`.

### Funcionalidades

- Recibir un número como parámetro.
- Retornar un array vacío cuando el número es menor que `1`.
- Generar un conteo regresivo desde `n` hasta `1`.
- Construir el resultado mediante llamadas recursivas.
- Crear un nuevo array en cada ejecución.
- Evitar el uso de variables globales.

### Conceptos practicados

- JavaScript
- Functions
- Recursion
- Base Case
- Recursive Case
- Arrays
- `.concat()`
- Return values
- Call Stack
- Pure Functions
- Problem Decomposition
- Function Calls

### Lo que aprendí

- Resolver problemas utilizando recursividad.
- Definir correctamente un caso base para detener una función recursiva.
- Reducir el problema en cada llamada utilizando `n - 1`.
- Construir arrays sin utilizar bucles.
- Combinar resultados mediante `.concat()`.
- Comprender cómo funciona la pila de llamadas (*Call Stack*).
- Evitar el uso de variables globales para mantener funciones independientes.
- Escribir funciones puras que siempre devuelven el mismo resultado para una misma entrada.

## 🇺🇸 English

This is exercise **102** in my freeCodeCamp JavaScript journey.

The goal was to build a recursive function that generates a countdown from a given number down to `1`, returning the result as an array.

Unlike a traditional solution, this exercise had to be solved **using recursion only**, without using loops (`for`, `while`), `Array.from()`, or array iteration methods such as `map()`, `filter()`, `reduce()`, or `forEach()`.

### Features

- Accept a number as input.
- Return an empty array when the number is less than `1`.
- Generate a countdown from `n` to `1`.
- Build the result through recursive function calls.
- Create a new array for every function call.
- Avoid using global variables.

### Concepts practiced

- JavaScript
- Functions
- Recursion
- Base Case
- Recursive Case
- Arrays
- `.concat()`
- Return values
- Call Stack
- Pure Functions
- Problem Decomposition
- Function Calls

### What I learned

- Solve problems using recursion.
- Define a proper base case to stop recursive execution.
- Reduce the problem on every recursive call using `n - 1`.
- Build arrays without using loops.
- Combine results using `.concat()`.
- Understand how the JavaScript call stack works.
- Avoid global variables to keep functions independent.
- Write pure functions that always return the same output for the same input.
