# 📅 Date Conversion Program

## 🇪🇸 Español

Este es el ejercicio número 92 de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue trabajar con el objeto `Date` de JavaScript y crear funciones capaces de mostrar una fecha en distintos formatos.

### Funcionalidades

- Obtener la fecha y hora actuales.
- Mostrar la fecha completa en la consola.
- Convertir una fecha al formato `MM/DD/YYYY`.
- Convertir una fecha al formato largo `Month Day, Year`.
- Utilizar configuración regional con `toLocaleDateString()`.

### Conceptos practicados

- JavaScript
- `Date`
- `new Date()`
- `.getMonth()`
- `.getDate()`
- `.getFullYear()`
- `.toLocaleDateString()`
- Functions
- Template literals
- Date formatting
- Console output

### Lo que aprendí

- Crear un objeto de fecha en JavaScript.
- Obtener el mes, día y año de una fecha.
- Recordar que `getMonth()` comienza desde cero.
- Crear funciones reutilizables para formatear fechas.
- Usar `toLocaleDateString()` con opciones de formato.
- Mostrar fechas en formatos numéricos y largos.
