Este es el ejercicio número **99** de mi recorrido de JavaScript en freeCodeCamp.

* Agregar productos al carrito.
* Agregar varias unidades del mismo producto.
* Mostrar la cantidad de unidades por producto.

* Calcular impuestos usando una tasa del `8.25%`.
* Calcular el total final.
* Mostrar y ocultar el carrito.
* Vaciar completamente el carrito.
* Confirmar antes de eliminar todos los productos.
* Avisar cuando el carrito ya está vacío.
* Actualizar la interfaz después de cada operación.

## 🇺🇸 English

This is exercise **99** in my freeCodeCamp JavaScript journey.

The goal was to build an interactive shopping cart for a dessert store. The application displays products, adds them to the cart, counts quantities, calculates subtotal, taxes, and total, and allows users to clear the cart after confirmation.

### Features

* Dynamically display a collection of products.
* Add products to the shopping cart.
* Add multiple units of the same product.
* Display the quantity of each product.
* Display the total number of items.
* Calculate the subtotal.
* Calculate taxes using an `8.25%` rate.
* Calculate the final total.
* Show and hide the shopping cart.
* Clear all items from the cart.
* Ask for confirmation before removing all products.
* Notify the user when the cart is already empty.
* Update the interface after every operation.

* Update text and HTML content from JavaScript.
* Render products using template literals.
* Work with dynamically created buttons.
* Convert an HTML collection into an array using spread syntax.
* Keep cart data and the interface synchronized.
* Use `.bind()` to preserve the `this` context inside an event listener.
* Ask for confirmation before performing a destructive action.
* Control cart visibility with a state variable.
* Build a responsive interface using Flexbox and media queries.
