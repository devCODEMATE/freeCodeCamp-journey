# 🥁 Drum Machine

> JavaScript Certification Project — freeCodeCamp

## 🇪🇸 Español

Este es el proyecto número 94 de mi recorrido de JavaScript en freeCodeCamp y forma parte de los proyectos requeridos para obtener la certificación.

El objetivo fue construir una máquina de ritmos interactiva que permita reproducir diferentes sonidos tanto al hacer clic en los pads como al presionar teclas específicas del teclado.

### Funcionalidades

- Nueve pads de percusión interactivos.
- Reproducción de sonidos mediante clic.
- Reproducción de sonidos mediante teclado.
- Teclas compatibles: `Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X` y `C`.
- Visualización del nombre del sonido reproducido.
- Elementos de audio integrados en cada pad.
- Respuesta visual al activar un pad.
- Compatibilidad con controles de teclado y mouse.
- Actualización dinámica del display.

## 🇺🇸 English

This is project number 94 in my freeCodeCamp JavaScript journey and one of the required projects for earning the certification.

The goal was to build an interactive drum machine that plays different sounds when users click the drum pads or press specific keys on the keyboard.

### Features

- Nine interactive drum pads.
- Sound playback through mouse clicks.
- Sound playback through keyboard input.
- Supported keys: `Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X`, and `C`.
- Display the name of the sound being played.
- Audio elements embedded inside each drum pad.
- Visual feedback when a pad is activated.
- Mouse and keyboard control support.
- Dynamic display updates.
