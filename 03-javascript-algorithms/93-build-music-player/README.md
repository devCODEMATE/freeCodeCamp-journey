# 🎵 Music Player

## 🇪🇸 Español

Este es el ejercicio número 93 de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue construir un reproductor de música interactivo utilizando JavaScript, manipulación del DOM y la API de audio del navegador.

La aplicación permite reproducir canciones, pausar el audio, avanzar o retroceder dentro de una lista, eliminar canciones y mantener actualizada la información del tema que se está reproduciendo.

### Funcionalidades

- Reproducir canciones.
- Pausar la reproducción.
- Reproducir la canción siguiente.
- Volver a la canción anterior.
- Eliminar canciones de la lista.
- Mostrar el título y el artista de la canción actual.
- Resaltar visualmente la canción activa.
- Actualizar el texto accesible del botón de reproducción.
- Reproducir automáticamente la siguiente canción cuando termina la actual.
- Reiniciar la lista cuando todas las canciones fueron eliminadas.

### Conceptos practicados

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Arrays of objects
- `Audio`
- `HTMLMediaElement`
- `.play()`
- `.pause()`
- `.currentTime`
- `ended` event
- Template literals
- Dynamic rendering
- Accessibility
- `aria-label`
- `aria-current`
- Event delegation
- State management

### Lo que aprendí

- Crear un reproductor utilizando el objeto `Audio`.
- Administrar una lista de canciones mediante un array de objetos.
- Mantener el estado de la canción actual.
- Cambiar entre canciones anteriores y siguientes.
- Actualizar dinámicamente la información del tema reproducido.
- Detectar cuándo termina una canción con el evento `ended`.
- Reproducir automáticamente la siguiente canción.
- Eliminar elementos de una playlist sin recargar la página.
- Aplicar delegación de eventos a elementos creados dinámicamente.
- Mejorar la accesibilidad mediante atributos ARIA.
- Mantener sincronizados el audio, los controles y la interfaz.

## 🇺🇸 English

This is exercise number 93 in my freeCodeCamp JavaScript journey.

The goal was to build an interactive music player using JavaScript, DOM manipulation, and the browser audio API.

The application allows users to play songs, pause audio, move forward or backward through a playlist, delete songs, and keep the current song information updated.

### Features

- Play songs.
- Pause playback.
- Play the next song.
- Return to the previous song.
- Delete songs from the playlist.
- Display the current song title and artist.
- Visually highlight the active song.
- Update the accessible text of the play button.
- Automatically play the next song when the current one ends.
- Reset the playlist when every song has been removed.

### Concepts practiced

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Arrays of objects
- `Audio`
- `HTMLMediaElement`
- `.play()`
- `.pause()`
- `.currentTime`
- `ended` event
- Template literals
- Dynamic rendering
- Accessibility
- `aria-label`
- `aria-current`
- Event delegation
- State management

### What I learned

- Build a music player using the `Audio` object.
- Manage a playlist with an array of objects.
- Track the currently playing song.
- Move between previous and next songs.
- Dynamically update the current song information.
- Detect when a song finishes with the `ended` event.
- Automatically play the next song.
- Remove songs from a playlist without reloading the page.
- Apply event delegation to dynamically rendered elements.
- Improve accessibility with ARIA attributes.
- Keep the audio, controls, and interface synchronized.
