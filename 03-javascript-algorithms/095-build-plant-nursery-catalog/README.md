# 🌿 Plant Nursery Catalog

## 🇪🇸 Español

Este es el ejercicio número **95** de mi recorrido de JavaScript en freeCodeCamp.

El objetivo fue desarrollar un sistema de administración para un vivero utilizando las estructuras de datos `Map` y `Set`. El programa permite almacenar distintas variedades de plantas, administrar su inventario, registrar ventas, eliminar elementos del catálogo y trabajar con colecciones de valores únicos.

### Funcionalidades

- Crear objetos para representar distintas variedades de plantas.
- Almacenar plantas e inventario utilizando un `Map`.
- Consultar si una planta existe dentro del catálogo.
- Obtener el inventario asociado a cada planta.
- Registrar ventas según el tamaño de maceta solicitado.
- Validar que exista suficiente stock antes de vender.
- Actualizar automáticamente las cantidades disponibles.
- Eliminar plantas del catálogo.
- Mostrar el contenido completo del inventario.
- Crear una colección de plantas únicas mediante un `Set`.
- Evitar elementos duplicados dentro del conjunto.

### Lo que aprendí

- Representar entidades mediante objetos de JavaScript.
- Utilizar objetos como claves dentro de un `Map`.

## 🇺🇸 English

This is exercise **95** in my freeCodeCamp JavaScript journey.

The goal was to build a plant nursery management system using the `Map` and `Set` data structures. The program stores different plant varieties, manages inventory, records sales, removes catalog entries, and works with collections of unique values.

### Features

- Create objects representing different plant varieties.
- Store plants and inventory using a `Map`.
- Check whether a plant exists in the catalog.
- Retrieve the inventory associated with each plant.
- Record sales by pot size.
- Validate that enough inventory is available before selling.
- Automatically update inventory quantities.
- Remove plants from the catalog.
- Display the complete inventory.
- Create a collection of unique plants using a `Set`.
- Prevent duplicate values from being stored.

- Add, retrieve, and remove entries from a `Map`.
- Iterate through a `Map` using `.forEach()`.
- Update object properties stored inside collections.

- Validate inventory before processing a sale.
- Simplify logic using early returns.
